The deferral race (scenario G1)

SOP resolution

Advantages

Deterministic: the same event and load always select the same sections, and the run record keeps their ids. The prompt holds a few sections instead of a client’s whole manual, which keeps cost and latency down. A client folder holds only what that client changed, and no other client’s files are read for its loads.

Disadvantages

A situation that no section names finds nothing: the run escalates to a Hero and the gap is recorded for the SOP editors. Editors must tag each section with intents from a fixed list, which the SOP lint checks, and the gate must classify a message into that list correctly.

Budgets

Enforced in code: the 240 s run deadline, 60 s per model call and at most 2 tool rounds (RuntimeConfig). Measured: the queue age against the 5-minute SLA and the cost per load against $1, flagged at 80% (application/metrics.py). The per-step ceilings and the spend split are targets, to be replaced with measured values.

Alternatives considered

OptionWhy not
One long prompt: full SOP and full history on every eventA 100-page SOP is roughly 50 to 70k tokens. Sent on about 80 events per load it breaks the $1 budget, and unrelated procedures push the model to act when it should not.
Compile SOPs into a workflow engineDeterministic, but every SOP change would need an engineer, and plain-English SOPs are ambiguous. We keep a small state machine for obligations only (attempts, deferral, timers); the steps stay in English.
One agent per stage or roleEach handoff adds a model call and drops context. The stage is already a selection key for SOP sections, so a separate agent adds latency and nothing else.
Vector search over the SOP textA missed section means silent wrong behavior that a test cannot assert. Not built: an event that no section names escalates to a Hero instead.
The model executes actions through toolsTools here are read-only. The model proposes a plan; code validates every action and the executor applies it in the commit, so a bad answer can be dropped but never half-applied.
